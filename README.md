# Netflix Data Analysis Dashboard

This project explores and visualizes global Netflix content trends using an interactive Excel (or Power BI) dashboard. It provides key insights into content distribution by genre, country, and year, as well as trends in movie vs. TV show releases.

##  Tools & Technologies Used

- **Microsoft Excel** / **Power BI**
  - Pivot Tables & Charts
  - Interactive Slicers (Filters)
  - Conditional Formatting
  - DAX/Power Query (if Power BI used)
- **Data Source:** Netflix Movies and TV Shows Dataset (from Kaggle or public source)


##  How to Use the Dashboard

1. Open the `Netflix_Analysis_Dashboard.xlsx` file in Excel  
   *(or open the `.pbix` file in Power BI Desktop if it’s a Power BI dashboard)*

2. Interact with:
   - Year filter to view trends over time
   - Country & Genre filters
   - TV Shows vs Movies comparison

3. Visuals include:
   - Top 10 genres
   - Content release trend over years
   - Most active countries
   - Movie vs TV Show distribution

##  Key Insights

- Netflix has seen consistent content growth since 2010, peaking in recent years.
- The U.S., India, and the U.K. contribute the most content.
- Drama and Comedy are the most dominant genres globally.
- TV Shows are rising faster than movies in the last 5 years.
